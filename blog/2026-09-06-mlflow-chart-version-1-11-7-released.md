# Announcing the Release of mlflow Chart Version 1.11.7

We are excited to share the launch of the **mlflow Helm chart version 1.11.7** on 2026-09-06, featuring **app version 3.16.0**. This update is packed with new features, enhancements, and community-driven improvements to streamline your experience with deploying mlflow on Kubernetes.

## What's New in the mlflow 1.11.7 Chart

This release not only introduces updates to the Helm chart (version 1.11.7) but also incorporates the latest application version (3.16.0). Here’s a quick overview of the changes:

- **Changed**: Updated the burakince/mlflow image version to 3.16.0
    - [Check the Upstream Project](https://hub.docker.com/r/burakince/mlflow)
- **Changed**: Updated the dependency on PostgreSQL from 18.8.13 to 18.8.17
    - [Visit ArtifactHub for Details](https://artifacthub.io/packages/helm/bitnami/postgresql)

To see the complete list of updates, don’t forget to check out the [release notes](https://github.com/community-charts/helm-charts/releases/tag/mlflow-1.11.7) on GitHub.
