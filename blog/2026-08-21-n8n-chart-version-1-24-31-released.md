# n8n chart version 1.24.31 released!

We are excited to share the launch of the **n8n Helm chart version 1.24.31** on August 21, 2026, featuring **app version 2.35.5**. This update introduces a range of new features, enhancements, and community-inspired improvements to streamline the deployment of n8n on Kubernetes.

## What's New in n8n 1.24.31 chart

This release includes updates to the Helm chart (version 1.24.31) as well as the underlying application (version 2.35.5). Here’s a brief overview of the key changes:

- **Changed**: Update n8nio/n8n image version to 2.35.5
    - [Upstream Project](https://github.com/n8n-io/n8n)

For a detailed list of changes, feel free to check out the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.31) on GitHub.
