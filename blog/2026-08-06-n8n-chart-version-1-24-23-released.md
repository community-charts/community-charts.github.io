# n8n chart version 1.24.23 has been released!

We are excited to share that the **n8n Helm chart version 1.24.23** is now available as of 2026-08-06, featuring **app version 2.33.4**. This release introduces new features, enhancements, and community-driven improvements, making it even easier to deploy n8n on Kubernetes.

## What's New in the n8n 1.24.23 Chart

The latest release includes updates to both the Helm chart (version 1.24.23) and the underlying application (version 2.33.4). Here’s a summary of the key changes:

- **Changed**: Updated n8nio/n8n image version to 2.33.4  
    - [Upstream Project](https://github.com/n8n-io/n8n)
- **Changed**: Increased redis dependency version from 27.0.18 to 28.0.0  
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/redis)
- **Changed**: Upgraded postgresql dependency from 18.8.4 to 18.8.6  
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/postgresql)

To explore all the changes in detail, please refer to the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.23) on GitHub.
