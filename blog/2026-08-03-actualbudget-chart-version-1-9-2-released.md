# Actualbudget Chart Version 1.9.2 Released!

We are excited to share the release of the **Actualbudget Helm chart version 1.9.2** on August 3, 2026, which features **app version 26.8.0**. This update unveils a host of new features, enhancements, and improvements driven by our vibrant community, all designed to streamline the deployment of Actualbudget on Kubernetes.

## What's New in Actualbudget 1.9.2 Chart

This release includes significant updates to the Helm chart (version 1.9.2) and the underlying application (version 26.8.0). Here’s a summary of the key changes:

- **Changed**: Updated the Actualbudget/Actual Server image version to 26.8.0.
    - [Upstream Project](https://hub.docker.com/r/actualbudget/actual-server)

For a comprehensive list of changes, please view the [release notes](https://github.com/community-charts/helm-charts/releases/tag/actualbudget-1.9.2) on GitHub.
