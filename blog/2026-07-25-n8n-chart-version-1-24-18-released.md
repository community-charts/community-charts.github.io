# n8n chart version 1.24.18 released!

We are excited to share that the **n8n Helm chart version 1.24.18** has been released on 2026-07-25, featuring **app version 2.31.6**. This update introduces new features, enhancements, and community-driven improvements, making it even easier to deploy n8n on Kubernetes.

## What's New in n8n 1.24.18 chart

This latest release brings updates to both the Helm chart (version 1.24.18) and the underlying application (version 2.31.6). Here’s a brief overview of the changes:

- **Changed**: Updated the n8nio/n8n image version to 2.31.6
    - [Upstream Project](https://github.com/n8n-io/n8n)
- **Changed**: Updated dependency redis from 27.0.15 to 27.0.17
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/redis)

For a more comprehensive list of changes, please visit the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.18) on GitHub.
