# n8n chart version 1.24.35 released!

We're excited to share the launch of the **n8n Helm chart version 1.24.35** on September 1, 2026, which features **app version 2.36.9**. This latest update brings a host of new features, enhancements, and improvements driven by our wonderful community, making it easier than ever to deploy n8n on Kubernetes.

## What's New in n8n 1.24.35 chart

This release features updates to both the Helm chart (version 1.24.35) and the underlying application (version 2.36.9). Here’s a quick overview of what’s new:

- **Changed**: Updated the n8nio/n8n image version to 2.36.9
    - [Upstream Project](https://github.com/n8n-io/n8n)

For a complete list of changes, feel free to check the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.35) on GitHub.
