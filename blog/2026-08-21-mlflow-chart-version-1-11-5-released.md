# mlflow chart version 1.11.5 released!

We are excited to share the launch of the **mlflow Helm chart version 1.11.5** on 2026-08-21, featuring **app version 3.15.1**. This release introduces a host of new features, enhancements, and valuable community-driven improvements to streamline your mlflow deployments on Kubernetes.

## What's New in mlflow 1.11.5 chart

This update showcases significant updates to both the Helm chart (version 1.11.5) and the underlying application (version 3.15.1). Here’s a summary of the key changes:

- **Changed**: Updated the oauth2-proxy image version to v7.15.4
    - [oauth2-proxy](https://quay.io/repository/oauth2-proxy/oauth2-proxy)
- **Changed**: Upgraded dependency postgresql from 18.8.6 to 18.8.12
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/postgresql)

For a comprehensive list of changes, please refer to the [release notes](https://github.com/community-charts/helm-charts/releases/tag/mlflow-1.11.5) on GitHub.
