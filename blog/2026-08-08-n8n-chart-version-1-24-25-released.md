# n8n chart version 1.24.25 released!

We are excited to announce the launch of the **n8n Helm chart version 1.24.25** on August 8, 2026, featuring **app version 2.33.7**. This latest update introduces new functionalities and community-driven improvements aimed at simplifying the deployment of n8n on Kubernetes.

## What's New in n8n 1.24.25 chart

This release focuses on updates to the Helm chart (version 1.24.25) and the underlying application (version 2.33.7). Here’s a glimpse of what’s included:

- **Changed**: Updated the n8nio/n8n image version to 2.33.7
    - [Upstream Project](https://github.com/n8n-io/n8n)

To view a complete list of changes, check out the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.25) on GitHub.
