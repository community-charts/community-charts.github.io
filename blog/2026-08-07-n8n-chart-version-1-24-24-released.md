# n8n chart version 1.24.24 released!

We are excited to share that the **n8n Helm chart version 1.24.24** is now available, released on 2026-08-07. This version features **app version 2.33.5** and includes an array of new features, enhancements, and community-driven improvements to streamline your n8n deployment on Kubernetes.

## What's New in n8n 1.24.24 chart

This release highlights updates to both the Helm chart (version 1.24.24) and the underlying application (version 2.33.5). Here’s an overview of the key changes:

- **Changed**: Updated the n8nio/n8n image version to 2.33.5
    - [Upstream Project](https://github.com/n8n-io/n8n)

To see the complete list of changes, check out the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.24) on GitHub.
