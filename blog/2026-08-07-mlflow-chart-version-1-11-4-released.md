# mlflow chart version 1.11.4 released!

We are excited to share that the **mlflow Helm chart version 1.11.4** is now available as of August 7, 2026. This release features **app version 3.15.1** and brings a host of new capabilities, enhancements, and community-driven improvements designed to simplify your mlflow deployment on Kubernetes.

## What's New in mlflow 1.11.4 chart

This update includes the latest changes to the Helm chart (version 1.11.4) and the underlying application (version 3.15.1). Here’s a snapshot of the significant updates:

- **Updated**: The burakince/mlflow image version is now 3.15.1
    - [Explore Upstream Project](https://hub.docker.com/r/burakince/mlflow)
- **Updated**: PostgreSQL dependency has been upgraded from version 18.8.4 to 18.8.6
    - [Check on ArtifactHub](https://artifacthub.io/packages/helm/bitnami/postgresql)

For a complete overview of changes, please refer to the [release notes](https://github.com/community-charts/helm-charts/releases/tag/mlflow-1.11.4) on GitHub.
