# MLflow Chart Version 1.11.3 Released!

We are excited to share that the **MLflow Helm chart version 1.11.3** has been officially released on August 1, 2026, showcasing **app version 3.15.0**. This update introduces a range of new features, enhancements, and community-driven improvements, all designed to simplify the deployment of MLflow on Kubernetes.

## What's New in MLflow 1.11.3 Chart

This release features updates to both the Helm chart (version 1.11.3) and the underlying application (version 3.15.0). Here are the highlights from the changelog:

- **Changed**: Updated the burakince/mlflow image version to 3.15.0
    - [Upstream Project](https://hub.docker.com/r/burakince/mlflow)
- **Changed**: Updated dependency on PostgreSQL from version 18.7.6 to 18.8.4
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/postgresql)

For a complete list of changes, please refer to the [release notes](https://github.com/community-charts/helm-charts/releases/tag/mlflow-1.11.3) on GitHub.
