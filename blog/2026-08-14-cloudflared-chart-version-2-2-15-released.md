# Cloudflared Chart Version 2.2.15 Released!

We are excited to share the launch of the **cloudflared Helm chart version 2.2.15** on August 14, 2026, featuring **app version 2026.8.1**. This update introduces new features, enhancements, and community-driven improvements, streamlining the deployment of cloudflared on Kubernetes.

## What's New in the Cloudflared 2.2.15 Chart

This release encompasses updates to both the Helm chart (version 2.2.15) and the underlying application (version 2026.8.1). Here’s a summary of the key changes:

- **Changed**: Updated the cloudflare/cloudflared image version to 2026.8.1
    - [Upstream Project](https://hub.docker.com/r/cloudflare/cloudflared)

For an in-depth overview of the changes, please refer to the [release notes](https://github.com/community-charts/helm-charts/releases/tag/cloudflared-2.2.15) on GitHub.
