# n8n chart version 1.24.20 released!

We are excited to share the release of the **n8n Helm chart version 1.24.20** on 2026-07-29, featuring **app version 2.32.5**. This update brings a range of new features, enhancements, and community-driven improvements, all designed to make deploying n8n on Kubernetes even easier.

## What's New in n8n 1.24.20 chart

This latest release includes updates to both the Helm chart (version 1.24.20) and the core application (version 2.32.5). Here’s a quick overview of the key changes:

- **Changed**: Updated the n8nio/n8n image version to 2.32.5
    - [Upstream Project](https://github.com/n8n-io/n8n)

For a thorough overview of all changes, please check the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.20) on GitHub.
