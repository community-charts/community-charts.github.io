# Announcing n8n chart version 1.24.32

We are excited to share the release of the **n8n Helm chart version 1.24.32** on August 22, 2026, which includes the latest **app version 2.35.7**. This update introduces a range of new features, enhancements, and community-driven improvements, all designed to streamline your experience of deploying n8n on Kubernetes.

## What's New in the n8n 1.24.32 Chart

With the release of the Helm chart version 1.24.32 and the accompanying application version 2.35.7, you can expect some noteworthy updates:

- **Changed**: Updated the n8nio/n8n image version to 2.35.7.
    - [Upstream Project](https://github.com/n8n-io/n8n)

To see all the updates in detail, view the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.32) on GitHub.
