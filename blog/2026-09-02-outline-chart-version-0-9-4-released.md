# Outline Chart Version 0.9.4 Released!

We are excited to share the launch of the **Outline Helm Chart version 0.9.4** on September 2, 2026, which comes with **app version 1.10.0**. This update introduces a range of new features and enhancements, all designed to improve your experience deploying Outline on Kubernetes.

## What's New in Outline 0.9.4 Chart

This release encompasses updates to the Helm chart (version 0.9.4) along with the underlying application (version 1.10.0). Here’s a glimpse of the detailed changelog:

- **Changed**: Updated the Outline image version to 1.10.0
    - [Upstream Project](https://hub.docker.com/r/outlinewiki/outline)
- **Changed**: Upgraded Redis dependency from version 27.0.15 to 28.0.12
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/redis)
- **Changed**: Updated PostgreSQL dependency from version 18.8.0 to 18.8.13
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/postgresql)

For a complete list of changes, please check the [release notes](https://github.com/community-charts/helm-charts/releases/tag/outline-0.9.4) on GitHub.
