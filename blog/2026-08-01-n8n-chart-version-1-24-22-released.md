# n8n chart version 1.24.22 released!

We are excited to share the launch of the **n8n Helm chart version 1.24.22** on August 1, 2026, featuring **app version 2.32.7**. This latest update brings a host of new features, enhancements, and improvements driven by our passionate community, making it easier than ever to deploy n8n on Kubernetes.

## What's New in n8n 1.24.22 chart

This release enhances the Helm chart (version 1.24.22) alongside the underlying application (version 2.32.7). Here’s a quick overview of what’s included:

- **Changed**: Updated the n8nio/n8n image version to 2.32.7
    - [Upstream Project](https://github.com/n8n-io/n8n)

For an in-depth look at all the changes, check out the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.22) on GitHub.
