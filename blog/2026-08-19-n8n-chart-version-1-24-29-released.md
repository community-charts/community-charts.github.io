# n8n chart version 1.24.29 released!

We are excited to share the announcement of the **n8n Helm chart version 1.24.29** as of 2026-08-19, which includes the new **app version 2.35.3**. This update enhances your experience with new features and improvements driven by our vibrant community, making it even easier to deploy n8n on Kubernetes.

## What's New in n8n 1.24.29 chart

This release brings noteworthy updates to both the Helm chart (version 1.24.29) and the application itself (version 2.35.3). Here’s a summary of what’s included:

- **Changed**: Updated the n8nio/n8n image version to 2.35.3
    - [Upstream Project](https://github.com/n8n-io/n8n)
- **Changed**: Updated dependency redis from 28.0.5 to 28.0.7
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/redis)
- **Changed**: Updated dependency postgresql from 18.8.9 to 18.8.12
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/postgresql)

For a thorough overview of all changes, please check the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.29) on GitHub.
