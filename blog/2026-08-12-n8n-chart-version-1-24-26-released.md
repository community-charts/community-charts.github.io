# n8n chart version 1.24.26 released!

We are excited to share the release of the **n8n Helm chart version 1.24.26** as of August 12, 2026, featuring the latest **app version 2.34.4**. This update introduces a range of new features and community-driven enhancements that streamline the deployment of n8n on Kubernetes.

## What's New in n8n 1.24.26 chart

In this release, we have made significant updates to both the Helm chart (version 1.24.26) and the underlying application (version 2.34.4). Here are the key changes:

- **Changed**: Updated n8nio/n8n image version to 2.34.4
    - [Upstream Project](https://github.com/n8n-io/n8n)
- **Changed**: Updated dependency redis from 28.0.0 to 28.0.2
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/redis)
- **Changed**: Updated dependency postgresql from 18.8.6 to 18.8.8
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/postgresql)

To explore the complete list of changes and enhancements, be sure to check out the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.26) on GitHub.
