# n8n chart version 1.24.19 released!

We are excited to share the launch of the **n8n Helm chart version 1.24.19** on July 28, 2026, featuring **app version 2.31.7**. This update is packed with new features, enhancements, and community-driven improvements that make deploying n8n on Kubernetes easier than ever.

## What's New in n8n 1.24.19 chart

The release comes with updates to both the Helm chart (version 1.24.19) and the underlying application (version 2.31.7). Here’s a summary of the significant changes:

- **Changed**: Updated n8nio/n8n image version to 2.31.7
    - [Upstream Project](https://github.com/n8n-io/n8n)
- **Changed**: Updated dependency for Redis from 27.0.17 to 27.0.18
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/redis)
- **Changed**: Updated dependency for PostgreSQL from 18.8.0 to 18.8.1
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/postgresql)

To view the complete list of changes, check out the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.19) on GitHub.
