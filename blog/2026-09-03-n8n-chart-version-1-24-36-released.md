# n8n chart version 1.24.36 released!

We are excited to share the release of the **n8n Helm chart version 1.24.36** on September 3, 2026, featuring **app version 2.37.7**. This latest update introduces new features, enhancements, and valuable community-driven improvements to streamline the process of deploying n8n on Kubernetes.

## What's New in the n8n 1.24.36 Chart

This release brings significant updates to the Helm chart (version 1.24.36) and the underlying application (version 2.37.7). Here's a closer look at the changes:

- **Changed**: Updated n8nio/n8n image version to 2.37.7
    - [Upstream Project](https://github.com/n8n-io/n8n)
- **Changed**: Upgraded PostgreSQL dependency from 18.8.13 to 18.8.14
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/postgresql)

For a complete list of changes, please refer to the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.36) on GitHub.
