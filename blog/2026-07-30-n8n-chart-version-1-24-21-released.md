# n8n chart version 1.24.21 released!

We are excited to share the release of the **n8n Helm chart version 1.24.21** on July 30, 2026, which includes **app version 2.32.6**. This update introduces new features, enhancements, and improvements inspired by our vibrant community, all aimed at streamlining your n8n deployment on Kubernetes.

## What's New in n8n 1.24.21 chart

The recent release encompasses updates to both the Helm chart (version 1.24.21) and the underlying application (version 2.32.6). Here’s a detailed look at the changes:

- **Changed**: Updated n8nio/n8n image version to 2.32.6
    - [Upstream Project](https://github.com/n8n-io/n8n)
- **Changed**: Updated dependency postgresql from 18.8.1 to 18.8.4
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/postgresql)

For a comprehensive list of changes, check out the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.21) on GitHub.
