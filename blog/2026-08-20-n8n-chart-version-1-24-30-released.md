# n8n chart version 1.24.30 released!

We are excited to share the release of the **n8n Helm chart version 1.24.30** on August 20, 2026, incorporating **app version 2.35.4**. This latest update introduces new features, enhancements, and community-driven improvements that streamline the deployment of n8n on Kubernetes.

## What's New in n8n 1.24.30 chart

The release includes updates for both the Helm chart (version 1.24.30) and the underlying application (version 2.35.4). Here’s a summary of the changes:

- **Changed**: Updated the n8nio/n8n image version to 2.35.4
    - [Upstream Project](https://github.com/n8n-io/n8n)

For a comprehensive list of changes, please refer to the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.30) on GitHub.
