# n8n chart version 1.24.28 released!

We are excited to share the release of the **n8n Helm chart version 1.24.28** on August 15, 2026, featuring **app version 2.34.6**. This new version introduces a host of features, enhancements, and community-driven improvements to streamline the deployment of n8n on Kubernetes.

## What's New in the n8n 1.24.28 Chart

This release includes significant updates to both the Helm chart (version 1.24.28) and the underlying application (version 2.34.6). Here’s a detailed overview of the changes:

- **Changed**: Updated n8nio/n8n image version to 2.34.6
    - [Upstream Project](https://github.com/n8n-io/n8n)
- **Changed**: Updated dependency redis from 28.0.2 to 28.0.5
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/redis)
- **Changed**: Updated dependency postgresql from 18.8.8 to 18.8.9
    - [ArtifactHub](https://artifacthub.io/packages/helm/bitnami/postgresql)

For a complete list of changes, be sure to check out the [release notes](https://github.com/community-charts/helm-charts/releases/tag/n8n-1.24.28) on GitHub.
