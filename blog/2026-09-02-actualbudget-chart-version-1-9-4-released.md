# Actualbudget Chart Version 1.9.4 Released!

We are excited to share the release of the **Actualbudget Helm chart version 1.9.4** on September 2, 2026, featuring **app version 26.9.0**. This update introduces new features, enhancements, and community-driven improvements that make deploying Actualbudget on Kubernetes even easier.

## What's New in Actualbudget 1.9.4 Chart

This release encompasses updates to both the Helm chart (version 1.9.4) and the underlying application (version 26.9.0). Here’s a quick look at the key changes:

- **Changed**: Updated the Actualbudget server image version to 26.9.0
    - [Upstream Project](https://hub.docker.com/r/actualbudget/actual-server)

For a complete list of updates, please check out the [release notes](https://github.com/community-charts/helm-charts/releases/tag/actualbudget-1.9.4) on GitHub.
